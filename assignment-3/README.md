# Overview

This folder contains 2 sub-folder
- [Task 1](./task1)
- [Taks 2](./task2)

Each sub-folder corresponding to the implementation and analysis for part 1 and part 2 of the assignment

# Execution
At the root folder run
```bash
python3 assignment-3/main.py
```

Follow the instruction to run task 1 or task 2

# Structure

## task1 folder
- [Deterministic Quicksort](./task1/deterministic_quicksort.py) - Implementation of the deterministic quicksort variant
- [Radomized Quicksor](./task1/randomized_quicksort.py) - Implementation of the randomized quicksort variant
- [Benchmark](./task1/benchmark.py) - Benchmark and testing setup
- [Analysis](./task1/analysis.md) - Details analysis of Quicksort run time

## task2 folder
- [Hash Table](./task2/hash_table.py) - Implementation of Hash table with chaining and universal hash function family
- [Demo](./task2/demo.py) - Set of hash table operations
- [Analysis](./task2/analysis.md) - Details analsysis of Hash Table run time

Distributed Event Queue

Each track below is one ordering key (queue). A token travels the track while its event is processing — only one token travels per track at a time, and its ack releases the next one waiting (backpressure: strictly sequential per key). Watch multiple tracks: they travel at the same time, independently — that's the concurrency across keys.

  • Waiting (FIFO line)
  • Traveling = processing now
  • Arrived / acked
